# 회원·게시판·댓글 API

## 실행 방법

— 필요한 JDK 버전, DB 준비, 실행 명령

## API 명세

— 엔드포인트마다 메서드, 주소, 인증 필요 여부, 요청 본문, 응답 본문, 상태 코드. 오류 응답의 모양

## 설계 설명

— 로그인 방식을 고른 이유, 엔티티 관계, N+1 을 막은 방법, 글 삭제 시 댓글 처리 방식

## 실행 결과

— curl (또는 HTTP 클라이언트)로 가입 → 로그인 → 글 쓰기 → 댓글 쓰기 → 목록 조회를 차례로 호출한 요청과 응답, 그리고 401·403 이 나는 요청과 응답 하나씩
